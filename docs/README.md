# OSCAL Viewer Documentation

This folder holds the deeper documentation for OSCAL Viewer. The root README is intentionally beginner-friendly; these pages provide more detail when you are ready to drill down.

## Guides

| Guide | Use it when... |
|---|---|
| [developer/README.md](developer/README.md) | You want to run the app locally, understand the codebase, add a feature, or work on tests. |
| [oscal-io-extensions/README.md](oscal-io-extensions/README.md) | You produce OSCAL JSON and want to understand first-class CSRC props plus OSCAL.io viewer hints. |
| [../samples/README.md](../samples/README.md) | You want example files for local testing or demos. |

## Recommended path for new contributors

1. Read the project overview in [../README.md](../README.md).
2. Run the app locally with the quick start commands.
3. Open one sample file from [../samples/README.md](../samples/README.md).
4. Read [developer/README.md](developer/README.md) before changing code.
5. Read [oscal-io-extensions/README.md](oscal-io-extensions/README.md) before adding first-class prop behavior or generating OSCAL.io viewer hints.
